Who uses this app

lospibardos_69 is a private tool used only by the owner of the LosPibardos channel to publish their own videos to their own TikTok account. It has no public sign-up and is not offered to other users.

Data we access

  • TikTok basic profile (user.info.basic): the account's open ID and display name, only to confirm which account is connected.
  • Posting permission (video.publish): used only to upload the videos the owner selects, with the caption the owner approves.
  • Creator settings returned by TikTok (available privacy levels, posting limits), only to choose valid options when posting.

We do not read followers, messages, comments, analytics or any other data.

How data is stored

The TikTok access and refresh tokens are stored only on the owner's private server, in a file readable only by that server's user. They are never shared, sold or sent to third parties, and are only sent to TikTok's own API.

How long we keep it

Tokens are kept until they expire or the owner revokes access. The owner can revoke access at any time from TikTok: Settings and privacy → Security → Manage app permissions. Revoking access makes the stored tokens stop working immediately; the owner can also delete them from the server at any time.

Cookies and tracking

This website and the app use no cookies, analytics or tracking.
